# Project Memory

Index of project-scoped facts worth remembering across sessions: decisions and their rationale, constraints, gotchas, and context not derivable from the code or git history.

**Convention**

- One markdown file per fact in this directory (`.claude/memory/`).
- Exactly one line in this index per memory: `- [Title](file.md) — hook`
- Never put memory content in this index — only titles, links, and short hooks.
- Check for an existing file before adding a duplicate.
- Update or delete memories that turn out to be wrong; do not leave stale ones.
- Do not record what the repo already says (code structure, git history, or anything already in `AGENTS.md`).

Corrections and standing always/never directives live in [`.claude/agent-notes.md`](../agent-notes.md), not here.

This directory replaces built-in / native project memory for this repo. Write new memories here so they are versioned and shared.
