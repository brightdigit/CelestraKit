# Agent Notes

Append-only running log of corrections and standing always/never directives for this project.

**Readers:** Read this file at the start of every session before doing work.

**Writers:** Whenever the user makes a correction or gives an always/never instruction, append one line here proactively (without being asked). Keep newest lines at the bottom. Use one line per entry. Never edit or delete an earlier entry — when a directive changes, append a new entry that supersedes the old one.

## Entry format

```text
- YYYY-MM-DD: [always|never|correction] Short directive in imperative form
```
